- 이미지 올리기 PUSH
 registry : dockerFile을 통해 생성된 이미지나 docker commit을 통해 생성된 이미지를 저장하는 곳
 public(공개) / private(비공개) registry 존재
 
 전제필수 작업
 1. docker login(docker logout) - hub.docker.com
 2. docker tag
 
 docker login - 홈페이지 인증을 통해 토큰 인증함
 docker info | grep Username - 로그인된 사용자 확인
 docker logout - 로그아웃
 
 토큰 발행하여 로그인
 docker hub에서 토큰 발행 후
 vi [filename] 에 토큰 저장
 cat [filename] | docker login --username [id] --password-stdin
 
 태그 작업
 docker image tag [imagename/tag] [tagName = username/tag]
 
 repository에 push
 docker push [tagName]
 
 다른 서버에서 해당 image를 다운받아 정상 동작되는지 확인되면 정상 push 됨
 
 이미지 공유 방법
 1. docker에 push
 2. dockerFile과 소스를 통해 github 업로드
 3. docker save를 통해 파일 백업 전달 후 docker load사용
 
- 이미지 백업 및 이전
 docker save 명령을 통해 *.tar 파일로 묶어 저장
 
 tar 파일 저장
 docker image save [imagename] > [filename].tar
 
 gz 파일 저장 |를 빼 먹을시 압축 되지 않은 파일만 생성
 docker image save [imagename] | gzip > [filename].tar.gz
 
 bz2 파일 저장(gz보다 10% 효율이 좋음) |를 빼 먹을시 압축 되지 않은 파일만 생성
 docker image save [imagename] | bzip2 > [filename].tar.bz2
 
 전달
 scp [filename] [도착지]
 
 load
 docker image load < [filename]
 
- 이미지 삭제 rm
 docker image rm [option] {image[:tag] | imageId}
 docker rmi [option] {image[:tag] | imageId}
 
 구동 중인 이미지는 삭제 안됨(중지필요) docker stop
